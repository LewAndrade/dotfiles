* How this file works

This file is the source of truth for =config.el=. Every =emacs-lisp= block below
tangles into that file, in document order.

Do not edit =config.el=. The next tangle overwrites it.

Three things trigger a tangle:

1. Saving any org file inside =~/.config/doom/=. The tangle runs in a background
   Emacs process, and the echo area reports the result.
2. Running =doom sync=. The =:config literate= module tangles before the sync
   reads your packages.
3. Running =org-babel-tangle= (=C-c C-v t=) by hand.

Two files stay hand written, because Doom reads them before the tangle hook
runs:

- =init.el= holds the module list. A tangled version of it lags one sync behind.
- =custom.el= belongs to Emacs itself.

Useful commands: =SPC h r r= reloads the config, and =+literate/find-heading=
jumps to any heading in this file.

** File header

Doom loads this file directly, so it needs the lexical binding cookie.

#+end_src

more than that per message, so a 1 MB buffer cuts the number of reads.

* Environment

** Emacs server

The =emacs-skills= Claude Code plugin drives this Emacs through =emacsclient=,

** PATH from fish

A GUI Emacs launched from Finder or the dock inherits a bare PATH. It cannot
find tools installed through nvm or brew, for example =claude-agent-acp=.
=exec-path-from-shell= imports the real PATH from fish.

The =-i= flag is required. Our fish nvm plugin activates node only under =status
is-interactive=, so a plain login shell returns a PATH without the nvm bin
directory. =-l -i= runs =nvm use=, which costs about half a second at startup.

#+begin_src emacs-lisp
(require 'exec-path-from-shell)
(setq exec-path-from-shell-shell-name "/opt/homebrew/bin/fish"
      exec-path-from-shell-arguments '("-l" "-i"))
(exec-path-from-shell-initialize)
#+end_src

** The =.project= problem

Doom makes projectile read =.project= as its dirconfig file, which holds ignore
rules. Eclipse, Buildship and jdtls all generate a =.project= XML file.
Projectile then tries to parse that XML as ignore rules and warns. Removing the
advice reverts dirconfig to the vanilla =.projectile=.

Doom also registers =.project= as a bottom up root marker. jdtls drops a
=.project= into every Gradle or Maven submodule. In a multi module repository
the bottommost match wins over the enclosing =.git=, so projectile roots at the
submodule. =agent-shell= keys off =projectile-project-root=, so it inherits the
same wrong root. After the fix, only real VCS roots and a =.projectile= that you
place yourself decide the root.

#+begin_src emacs-lisp
(after! projectile
  (advice-remove #'projectile-dirconfig-file #'doom--projectile-dirconfig-file-a)
  (setq projectile-project-root-files-bottom-up
        (delete ".project" projectile-project-root-files-bottom-up)))
#+end_src

* Language servers

** lsp-mode

Signature help and documentation popups are off, because they fight with corfu
for the same screen space. =lsp-completion-provider= is =:none= for the same
reason: corfu owns completion. Indentation stays with Emacs, so the language
server does not reformat on every edit.

=lsp-use-plists= needs the =lsp-use-plists=1= environment variable at build
time. Doom sets it, so plists are safe here and they cut deserialization cost.

#+begin_src emacs-lisp
(use-package! lsp-mode
  :commands lsp
  :config
  (setq lsp-headerline-breadcrumb-enable nil
        lsp-signature-render-documentation nil
        lsp-signature-function 'lsp-signature-posframe
        lsp-signature-auto-activate nil
        lsp-completion-provider :none
        lsp-semantic-tokens-enable t
        lsp-enable-indentation nil
        lsp-inlay-hint-enable t
        lsp-idle-delay 0.05
        lsp-use-plists t)
#+end_src

The default ignore list covers Maven =target= but not the Gradle generated
directories. Multi module Gradle projects therefore pass
=lsp-file-watch-threshold= and prompt on every start. Ignoring the noisy
directories keeps file watching enabled.

#+begin_src emacs-lisp
  (dolist (dir '("[/\\\\]build\\'"
                 "[/\\\\]\\.gradle\\'"
                 "[/\\\\]\\.tmp\\'"
                 "[/\\\\]bin\\'"
                 "[/\\\\]\\.settings\\'"))
    (add-to-list 'lsp-file-watch-ignored-directories dir))
#+end_src

A refactor across many files leaves every touched buffer modified but unsaved.
Saving after the edits keeps the buffers and the language server in agreement.

#+begin_src emacs-lisp
  (add-hook 'lsp-after-apply-edits-hook (lambda (&rest _) (save-buffer))))
#+end_src

** Scrolling another window

A common layout is code on top and a compilation or test buffer below. These
commands scroll that bottom window without leaving the code. The window must
span the full frame width, which is how Doom lays out popups.

#+begin_src emacs-lisp
(defun scroll-up-bottom-window ()
  "Scroll up bottom window"
  (interactive)
  (save-selected-window
    (when-let ((bottom-window (-first (lambda (w)
                                        (and (window-full-width-p w)
                                             (not (eq w (get-buffer-window))))) (window-list))))
      (select-window bottom-window)
      (scroll-up-line))))

(defun scroll-down-bottom-window ()
  "Scroll down bottom window"
  (interactive)
  (save-selected-window
    (when-let ((bottom-window (-first (lambda (w)
                                        (and (window-full-width-p w)
                                             (not (eq w (get-buffer-window))))) (window-list))))
      (select-window bottom-window)
      (scroll-down-line))))
#+end_src

* Style

** Fonts

Maple Mono NF ships one family, so contrast between contexts comes from weight
and slant rather than from sibling families.

These settings apply unconditionally. Doom applies fonts per frame, which
matters under the daemon where no display exists at load time, and it falls back
gracefully when a family is missing.

#+begin_src emacs-lisp
(defvar my/font "Maple Mono NF")

(setq doom-font (font-spec :family my/font :size 14)
      doom-variable-pitch-font (font-spec :family my/font :size 14)
      doom-big-font (font-spec :family my/font :size 20)
      doom-symbol-font (font-spec :family my/font)
      doom-emoji-font (font-spec :family "Noto Emoji"))
#+end_src

The emoji font needs an explanation. Without it, Emacs falls back to Apple Color
Emoji, which is colorful and double width, and which looks wrong against these
themes. No installed mono font covers those glyphs, so Noto Emoji fills the gap.

Doom's =doom-init-fonts-h= routes this font at the =emoji= script, which covers
the folder and herb glyphs. It also appends the font after =doom-symbol-font= for
the =symbol= script, which covers pause, stopwatch and spinner. Maple lacks
those three, so they fall through to Noto. One setting therefore covers every
Claude Code glyph.

* AI coding

Claude Code runs inside Emacs through =agent-shell=, which speaks the Agent
Client Protocol. The shell renders in a native Emacs buffer, so there is no
terminal emulator and no glyph or spinner problem. =claude-code-ide.el= did the
same job through a terminal and came out on 2026-09-12.

Packages stay declared in =packages.el=, which Doom reads at sync time and which
stays hand written.

** Entry points

All three commands pass a prefix argument to =agent-shell=, which forces a new
shell instead of a switch to an existing one.

Rooting sessions at =~/Dev= is deliberate. The resume picker groups sessions by
their working directory, so one shared root keeps every session in a single flat
list, and no directory needs remembering.

#+begin_src emacs-lisp
(defun my/agent-shell-dev ()
  "Start a Claude agent shell rooted at `~/Dev'.

Rooting sessions here on purpose: the resume picker groups by the
session's cwd, so one shared root keeps every session in a single flat
list and there is never a directory to remember."
  (interactive)
  (require 'agent-shell)
  (let ((default-directory (expand-file-name "~/Dev/")))
    (agent-shell '(4))))

(defun my/agent-shell-in-dir (dir)
  "Start an agent shell in DIR."
  (interactive "DAgent shell in directory: ")
  (require 'agent-shell)
  (let ((default-directory (file-name-as-directory dir)))
    (agent-shell '(4))))

(defun my/agent-shell-select-agent ()
  "Start an agent shell, choosing the agent explicitly.

`agent-shell-preferred-agent-config' resolves to Claude and suppresses
the picker, so reaching any other agent needs this explicit path."
  (interactive)
  (require 'agent-shell)
  (agent-shell-start :config (agent-shell-select-config :prompt "Agent")))
#+end_src

** Notifications

A shell that waits on a permission prompt needs to reach you while Emacs sits in
the background. These functions post a Notification Center banner, and a click
on that banner focuses Emacs and jumps to the shell that raised it.

*** What terminal-notifier requires

This needs =terminal-notifier= 3.x. Version 2.0.0 was built on the removed
=NSUserNotification= API, where =-execute=, =-activate= and =-open= silently
never fired.

Never pass =-sender= or =-appIcon=. Version 3.x accepts both and ignores them.
Under 2.0.0 they transferred ownership of the notification away from
=terminal-notifier=, which broke =-list= and =-remove= as well as clicks. For an
Emacs icon, build a renamed copy of the app with =make icon ICON=... APP_NAME=...=
instead.

After an upgrade the Cellar path changes, and macOS refuses authorization with
exit code 3 and no prompt. Repair it with the command below, then read
=terminal-notifier -diagnose= for the authorization state and alert style.

#+begin_example
lsregister -f /opt/homebrew/Cellar/terminal-notifier/<version>/terminal-notifier.app
#+end_example

window is selected; hence the explicit focus call. Falls back to the most
recently used shell, because `agent-shell-hq-label' can rename a buffer
between the notification arriving and the click."
  (when-let* ((buffer (or (get-buffer name)
                          (car (and (fboundp 'agent-shell-buffers)
                                    (agent-shell-buffers))))))
    (if-let* ((window (get-buffer-window buffer t)))
        ;; Already on screen: focus that window rather than displaying the
        ;; buffer again, which would split.
        (progn
          (select-frame-set-input-focus (window-frame window))
          (select-window window))
      (select-frame-set-input-focus (selected-frame))
      ;; Follow `agent-shell-display-action' so a click puts the shell exactly
      ;; where `SPC l l' would. A bare `pop-to-buffer' ignores it and splits the
      ;; window you were reading.
      (pop-to-buffer buffer (or (bound-and-true-p agent-shell-display-action)
                                '(display-buffer-same-window))))
    t))

*** The click helper

The click action needs care. =-execute= fires only when it receives a bare
script path that takes no arguments. A compound command with quoted arguments
never fires on click, even though the identical string runs correctly under =sh
-c=.

The buffer name therefore travels through a file, not through the command line.
The generated script contains no interpolation at all, so nothing from a buffer
name reaches a shell.

#+begin_src emacs-lisp
(defvar my/agent-shell-notify-dir
  (expand-file-name "agent-shell/" doom-cache-dir)
  "Directory holding the notification click helper and its target file.")

(defun my/agent-shell--notify-target-file ()
  "Return the file recording which buffer the last notification came from."
  (expand-file-name "click-target" my/agent-shell-notify-dir))

(defun my/agent-shell--notify-script ()
  "Return the path of the click helper script, writing it when out of date.

`-execute' is handed a bare script path taking no arguments, and the elisp
inside contains no interpolation whatsoever. A compound command with
quoted arguments does not fire on click, even though the identical string
runs correctly under `sh -c', so the buffer name travels through a file
rather than through the command line."
  (let* ((script (expand-file-name "notify-click.sh" my/agent-shell-notify-dir))
         (client (or (executable-find "emacsclient") "emacsclient"))
         (content (concat "#!/bin/sh\n"
                          "exec " client " -e '(my/agent-shell-notify-click)'\n")))
    (make-directory my/agent-shell-notify-dir t)
    (unless (and (file-exists-p script)
                 (equal content (with-temp-buffer
                                  (insert-file-contents script)
                                  (buffer-string))))
      (with-temp-file script (insert content))
      (set-file-modes script #o755))
    script))

(defun my/agent-shell-notify-click ()
  "Show the shell that raised the most recent notification.
Reads the target name from a file, so nothing is interpolated into the
shell command that invokes this."
  (interactive)
  (my/agent-shell-show-buffer
   (let ((file (my/agent-shell--notify-target-file)))
     (when (file-exists-p file)
       (string-trim (with-temp-buffer
                      (insert-file-contents file)
                      (buffer-string)))))))
#+end_src

*** Sampling a transcript

Whole transcripts cost too much to send, and one file reached 368 KB. The
sampling budget caps the cost at a predictable size.

Reading the head alone mislabels long sessions that open with boilerplate. That
368 KB transcript began with a =/context= command and earned the label "token
context verification only". Three offsets fix this.

#+begin_src emacs-lisp
(defvar my/agent-shell-label-context-chars 9000
  "Sampling budget per session, in bytes, when labelling.
Caps cost at a predictable size instead of sending whole transcripts.
Counted in bytes because `insert-file-contents' takes byte offsets.")

(defvar my/agent-shell-label-min-file-chars 1200
  "Smallest per-file slice of the sampling budget, however many files there are.")

(defun my/agent-shell--file-sample (file budget)
  "Return up to BUDGET characters sampled from FILE.

Reads from three offsets rather than the head alone. Reading only the
opening mislabels long sessions whose first exchange is boilerplate: one
368 KB transcript opened with a `/context' command and got labelled
\"token context verification only\"."
  (let* ((size (or (file-attribute-size (file-attributes file)) 0))
         (offsets (if (<= size budget)
                      (list 0)
                    (list 0 (floor (* size 0.4)) (floor (* size 0.75)))))
         (each (max 400 (/ budget (length offsets))))
         (parts nil))
    (dolist (offset offsets)
      (push (with-temp-buffer
              (insert-file-contents file nil offset (min size (+ offset each)))
              (buffer-string))
            parts))
    (mapconcat #'identity (nreverse parts) "\n[...]\n")))

(defun my/agent-shell--session-sample (files)
  "Return a capped text sample drawn from every file in FILES, oldest first.

One session's work is frequently split over several transcript files, so
the budget is shared between them. Transcript names are timestamps, so
sorting by name sorts chronologically."
  (let* ((sorted (sort (copy-sequence files)
                       (lambda (a b)
                         (string< (file-name-base a) (file-name-base b)))))
         (per-file (max my/agent-shell-label-min-file-chars
                        (/ my/agent-shell-label-context-chars
                           (max 1 (length sorted))))))
    (mapconcat (lambda (file) (my/agent-shell--file-sample file per-file))
               sorted
               "\n\n")))
#+end_src

*** Running the labeller

=SPC l L= labels every unlabelled session, and a prefix argument relabels all of
them. Sessions run one at a time to stay clear of rate limits.

#+begin_src emacs-lisp
(defun my/agent-shell--label-async (session-id files callback)
  "Generate and store a label for SESSION-ID sampled from FILES.

FILES is every transcript belonging to the session.  Calls CALLBACK with
(LABEL ERROR): exactly one is non-nil.  Unlike `agent-shell-hq-label', a
non-zero exit or an API error is reported rather than silently discarded."
  (let* ((output "")
         (proc (make-process
                :name "agent-shell-label"
                :buffer nil
                :noquery t
                :connection-type 'pipe
                :command (append my/agent-shell-label-command
                                 (list (concat my/agent-shell-label-prompt
                                               (my/agent-shell--session-sample files))))
                :filter (lambda (_proc chunk)
                          (setq output (concat output chunk)))
                :sentinel
                (lambda (proc event)
                  (unless (process-live-p proc)
                    (let ((text (string-trim output)))
                      (if (and (string-prefix-p "finished" event)
                               (not (string-empty-p text))
                               (not (string-match-p "\\`API Error" text)))
                          (progn
                            (agent-recall-metadata-put session-id 'label text)
                            (funcall callback text nil))
                        (funcall callback nil
                                 (string-trim
                                  (concat (string-trim event) " " text))))))))))
    ;; `claude -p' reads stdin when it is a pipe, so close it or the process
    ;; never exits and the sentinel never runs.
    (process-send-eof proc)
    proc))

(defun my/agent-shell--label-next (pending done failed total)
  "Label the head of PENDING, then recurse. Sequential to stay rate-limit safe."
  (if (null pending)
      (message "agent-shell: labelled %d of %d sessions (%d failed)"
               done total failed)
    (let ((id (caar pending))
          (files (cdar pending))
          (rest (cdr pending)))
      (message "agent-shell: labelling session %d of %d…" (1+ done) total)
      (my/agent-shell--label-async
       id files
       (lambda (label err)
         (when err
           (message "agent-shell: label failed for %s: %s" id err))
         (my/agent-shell--label-next rest
                                     (if label (1+ done) done)
                                     (if label failed (1+ failed))
                                     total))))))

(defun my/agent-shell-label-sessions (&optional relabel)
  "Give every past session a short generated label.

Samples each session's transcripts and asks `my/agent-shell-label-model'
for a summary, storing it with `agent-recall-metadata-put'.  Skips
sessions that already have a label, so this is safe to re-run; with a
prefix argument RELABEL, regenerates every label.

Groups by session id rather than iterating transcript files. Several files
routinely share one session id (resuming a session starts a new
transcript), and writing per file meant the surviving label came from
whichever file `maphash' visited last, in arbitrary order.

Walks `agent-recall--index' rather than the filesystem, because that index
already maps transcript files to session ids."
  (interactive "P")
  (require 'agent-recall)
  (agent-recall--index-ensure)
  (let ((by-session (make-hash-table :test 'equal))
        (pending nil))
    (maphash (lambda (file entry)
               (when (file-exists-p file)
                 (when-let* ((id (or (plist-get entry :session-id)
                                     (agent-recall--resolve-session-id file))))
                   (puthash id (cons file (gethash id by-session)) by-session))))
             agent-recall--index)
    (maphash (lambda (id files)
               (when (or relabel (not (agent-recall-session-label id)))
                 (push (cons id files) pending)))
             by-session)
    (if (null pending)
        (message "agent-shell: every session already has a label")
      ;; Bind before measuring: `nreverse' leaves `pending' pointing at the last
      ;; cons, so `(length pending)' in the same argument list would return 1.
      (let ((items (nreverse pending)))
        (my/agent-shell--label-next items 0 0 (length items))))))
#+end_src

#+end_src

faults here. The =haiku= alias resolves to =claude-haiku-4-5=, which this gateway
rejects with a 400, and hq's sentinel acts only on "finished", so it dropped the
error, reported "labeling" and then did nothing. Separately, a plain =claude -p=
persists a session, so every label added a junk entry to the =SPC l a= picker.

#+begin_src emacs-lisp
  (setq agent-shell-hq-label-command my/agent-shell-label-command))
#+end_src

*** agent-recall

Full text search over past transcripts with ripgrep, then a resume.
=agent-recall-search-paths= defaults to nil and =agent-recall-reindex= requires
it. Every transcript lives in some =.agent-shell/transcripts/= directory beneath
=~/Dev=.

#+begin_src emacs-lisp
(use-package! agent-recall
  :after agent-shell
  :config
  (setq agent-recall-search-paths '("~/Dev")))
#+end_src

** Extensions that were rejected

Thirteen community extensions were evaluated on 2026-09-12. The list below
records why each one lost, because several reasons are not obvious.

| Extension                  | Reason it lost                                                                         |
|----------------------------+----------------------------------------------------------------------------------------|
| =permission-transient=     | Replaces the permission responder, which skips the =permission-request= event entirely  |
| =knockknock=               | Posframe only, never reaches Notification Center, and needs an unmerged upstream change |
| =agent-shell-hud=          | Requires xwidgets. This Emacs is =--with-ns=, so =xwidget-internal= is nil              |
| =agent-shell-sidebar=      | Pinned to agent-shell 0.17.x, and =agent-shell-display-action= covers the need          |
| =agent-shell-org-transcript= | Writes org-roam nodes, and there is no org-roam here                                 |
| =agent-review=             | Long stale                                                                             |
| =agent-shell-workspace=    | Long stale, and hq supersedes it                                                       |
| =agent-shell-queue=        | =agent-shell-prompt-queue= already ships built in                                       |
| =macext=                   | Good, but unlicensed. Only the notification part was wanted, so it was reimplemented    |
| =agent-shell-pet=          | Installed, tried and removed the same day                                              |

Two traps are worth repeating. =permission-transient= kills notifications
silently, because the branch that emits =permission-request= never runs. Passing
=-sender= to =terminal-notifier= looks harmless and breaks clicks.
